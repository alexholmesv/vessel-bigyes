02 / Principles
Four rules
we follow.
Improv has rules. So does the brand. Everything else is improvisation.
01

Loud type, quiet UI.

Headlines do the heavy lifting. Forms, tables, and chrome stay almost invisible so the words and faces can shout.

02

One yellow, used boldly.

Marigold yellow is the brand. It's a highlighter, a stage light, a sticker. Use it as a block — never as a gradient, never as a tint behind body text.

03

Photography over illustration.

Real performers, real audiences, mid-laugh. If you don't have the photo yet, use a striped placeholder. Don't fake it with stock or AI art.

04

Paper, not screens.

The base is warm paper, not white or grey. Borders are hairline ink. The whole thing should read like a risograph poster before it reads like a website.

03 / Color
Paper, ink,
marigold, tomato.
Four tones do almost everything. Yellow is the only accent that earns a name. Tomato red is reserved for warnings, live states, and the occasional underline.

08 / Layout
12 columns,
but use 2 or 3.
A 12-col grid with 24-px gutters underpins everything. Real layouts almost never use all twelve — they break into 2- or 3-up bands with one column of breathing room. Headlines may bleed across the gutter into the next column on purpose.

09 / Motion
Snap, don't
fade.
Movement should feel like a cue card slamming on a desk. 120 – 180 ms, hard easing. Nothing dissolves. Hover offsets are instant. Page transitions clip, not fade.
Snap-in

120 ms · cubic-bezier(.2,.8,.2,1)

Buttons, hovers, drawers, modal entry. The default for almost everything.

Stamp

180 ms · cubic-bezier(.7,0,.2,1.4)

For confirmations — the "yes" stamp on a checkout. Slight overshoot, then settle.

Never

Fade · ease-in-out · 300 ms+

No long fades, no parallax scroll, no animated gradients. We're a theatre brand, not a screensaver.

10 / Mobile
Mobile-first,
poster-loud.
The whole system collapses to a single column on phones — but it never loses its voice. Type stays loud (only one step down from desktop). Hit targets are 44 px minimum. Rows become cards. The yellow keeps shouting.

Breakpoints

Default = mobile. Add columns only above sm 640, md 768, lg 1024, xl 1280.

Flex everywhere

Every row uses display:flex with flex-wrap:wrap. No fixed widths below 1024.

Hit targets

Min 44×44 px. Buttons are padding:14px 16px on mobile, not 12×18.

Type ramp shrinks once

Display-xl 96 → 56 on mobile. H1 40 → 28. Body stays 15.

Stack maps · how each desktop layout collapses
Roster table

Table → stacked cards

Below md 768 the <table> becomes a .mob-roster flex column. Each row collapses to: avatar, name + meta, end-tag. Tap row to expand (no separate "Open" button needed).

KPI strip

4-up row → 2×2 grid

grid-cols-2 md:grid-cols-4. One card per breakpoint stays marigold to keep the system colour visible on a phone.

Sidebar nav

Sidebar → bottom tab bar

Below lg 1024, the left sidebar moves to a 4-tab bottom bar (Stage / Cohorts / Shows / You). Secondary nav goes inside the hamburger drawer. The active tab fills with marigold — same gesture as the desktop active state.

Show cards

3-up grid → 1-up stack

grid-cols-1 sm:grid-cols-2 lg:grid-cols-3. Photo stays at top, body unchanged. Price + CTA in the footer go full-width, side-by-side via flex.

Primary CTA

Inline → sticky bottom

On detail pages (show, class, profile), the primary CTA detaches into a position:sticky; bottom:0 bar that sits above the tab bar. Marigold background, ink text, full width.

Hero display

Two-step type ramp

Display-xl is 56 px default, 72 px at sm, 96 px at md+. Use clamp(56px, 8vw, 148px) for fluid display headlines.
